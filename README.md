# Зерно — сравнение specialty-кофе у российских обжарщиков

Один и тот же лот у разных обжарщиков рядом: цена за 100 г, фасовки, обработка, сорт, высота,
дескрипторы, оценка сроков доставки в ваш город и кнопка «Заказать» на сайт обжарщика.

## Как устроено

```
roasters.yaml        реестр обжарщиков (имя, город, сайт, доставка) — единственное, что правится руками
scraper/
  adapters.py        Shopify · WooCommerce · InSales · Tilda · generic (sitemap + JSON-LD/OpenGraph)
  normalize.py       страна/регион/обработка/сорт/высота/SCA/дескрипторы из текста (RU+EN синонимы)
  match.py           склейка одинаковых лотов («Эфиопия Конга натуральная» = «Ethiopia Konga Natural»)
  run.py             обход → нормализация → склейка → картинки (webp) → слияние с историей
site/                статический сайт (index.html, app.js, app.css) + data/catalog.json + img/
data/raw/            сырые выгрузки по обжарщикам; data/report.md — отчёт последнего прогона
```

**Новые лоты подхватываются сами:** платформа сайта определяется заново при каждом запуске,
а generic-адаптер читает `sitemap.xml` и разметку товара (JSON-LD / OpenGraph), которая есть
почти у любого магазина. Опубликовал обжарщик новую карточку — на следующем прогоне она в каталоге,
с плашкой «Новинка» 14 дней, в разделе «Новинки» и в `data/report.md`.

Ежедневная проверка (GitHub Actions, 03:17 МСК):
- позиция «нет в наличии» или пропавшая с сайта — сразу удаляется из каталога;
- новая позиция — добавляется с плашкой «Новинка» на 14 дней; вернувшаяся в продажу — без плашки
  (даты появления и история цен хранятся в `data/seen.json`);
- что добавилось и удалилось — в `data/changes.json` (журнал за 90 проверок) и в `data/report.md`;
- защита от ложных удалений: если сайт не ответил или отдал < 50% обычного каталога, берутся
  данные прошлой выгрузки, но не старше 3 суток — иначе позиции обжарщика скрываются.

## Запуск

```bash
pip install -r requirements.txt
python -m scraper.run                  # все обжарщики
python -m scraper.run --only tasty,tab # выборочно
python tests/test_pipeline.py          # тесты разбора и склейки
cd site && python -m http.server 8000  # открыть http://localhost:8000
```

## Автообновление

- **GitHub Actions** — `.github/workflows/update.yml`: раз в сутки (03:17 МСК) парсит, коммитит данные и
  публикует `site/` на GitHub Pages. Включите Pages → Source: GitHub Actions.
- **Свой сервер в РФ (рекомендуется):** часть российских сайтов блокирует зарубежные IP
  раннеров GitHub. `deploy/update.sh` в crontab + `deploy/nginx.conf`.

## Добавить обжарщика

Допишите в `roasters.yaml` `id`, `name`, `city`, `site`; по желанию `catalog` (страница каталога
кофе), `delivery`, `roast_lag`. Больше ничего не нужно.

Сроки доставки — оценка по зонам СДЭК/Почты + время до отправки (`roast_lag`), а не обещание магазина.
